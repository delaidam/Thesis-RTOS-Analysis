# FreeRTOS-TetriSaraj

This work builds on top of:

1) [TetriSaraj-Tango](https://github.com/chili-chips-ba/openXC7-TetriSaraj/tree/main/99.more-boards/0.tang-nano-9k) project, authored by @juninho99

2) [openXC-TetriSaraj](https://github.com/chili-chips-ba/openXC7-TetriSaraj), authored by @kerimbavcic and @harunkovacevic 

It aims to convert the game algorithm from baremetal 'C' application to hosted framework.


### Additional references:

3) [TangNano9K](https://wiki.sipeed.com/hardware/en/tang/Tang-Nano-9K/Nano-9K.html) hardware platform
4) [GowinEDA](https://www.gowinsemi.com/en/support/download_eda) tools
5) [PicoRV32](https://github.com/YosysHQ/picorv32) RISC-V micro-controller
6) [FreeRTOS](https://www.freertos.org/Using-FreeRTOS-on-RISC-V) framework
7) [eduBOS5](https://fpga-ignite.github.io/presentations-pdf/presentation16.pdf) Bosnian RISC-V micro-controller

> Delaida, ovo je samo pocetno sjeme. Slobodno dodaji, brisi, i dalje gradi.
