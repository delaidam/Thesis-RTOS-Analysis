# FreeRTOS-TetriSaraj

This work builds on top of:

1) [TetriSaraj-Tango](https://github.com/chili-chips-ba/openXC7-TetriSaraj/tree/main/99.more-boards/0.tang-nano-9k) for [TangNano9K](https://wiki.sipeed.com/hardware/en/tang/Tang-Nano-9K/Nano-9K.html), authored by @juninho99

2) [openXC-TetriSaraj](https://github.com/chili-chips-ba/openXC7-TetriSaraj), authored by @kerimbavcic and @harunkovacevic 

and seeks to convert the game all from baremetal 'C' to hosted framework.
